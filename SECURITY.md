# Security Policy

## Supported versions

Security fixes are provided for the latest published minor version of `mcp-replay`.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities.

Report security issues through GitHub Security Advisories for this repository. If that is unavailable, contact the maintainer through the email listed on the GitHub profile for `mstuart` and include:

- Affected version
- Reproduction steps or proof of concept
- Impact and any known mitigations

You should receive an acknowledgment within 7 days.
